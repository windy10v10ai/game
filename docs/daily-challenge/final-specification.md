# 每日挑战最终系统规格

## 1. 每日结构

每个挑战日包含：

1. 一个全服共同任务；
2. 每名玩家最多完成 `3` 轮个人任务；
3. 每轮展示 `3` 个候选：`2` 个不同类别的通用任务和 `1` 个英雄专属任务；
4. 玩家每轮三选一，完成后自动进入下一轮；
5. 第三轮完成后显示当天三轮记录和奖励总计，不再生成候选。

比赛按服务器记录的比赛开始时间归属挑战日。玩家必须在比赛开始后 `10` 分钟内接取本轮任务，该局才计算个人任务进度；未接取不累计。

## 2. 星级与奖励

每个候选独立随机为 `1`、`2` 或 `3` 星，允许三个候选出现相同星级。任务生成后必须冻结：

- `star`；
- `target`；
- `rewardSeasonPoint`；
- 任务文案和配置版本。

默认奖励档位为：

| 星级 |               推荐目标倍率 | 赛季积分 |
| ---- | -------------------------: | -------: |
| 1 星 | 二星目标的 `0.5`～`0.8` 倍 |       80 |
| 2 星 |         审核任务池基准目标 |      100 |
| 3 星 |   二星目标的 `1.5`～`2` 倍 |      120 |

实际界面和发奖始终以任务快照中的 `target` 与 `rewardSeasonPoint` 为准，不由客户端按星级重新计算。

## 3. 个人任务流程

- 未接取时不产生个人进度。
- 接取后，本轮任务锁定，不能更换；可查看正式进度、当前局暂存进度和同步倒计时。
- 当前局进度每 `5` 分钟自动同步一次，也允许手动同步；同步值只是暂存展示。
- 只有按照游戏现有规则正常结算的比赛才写入正式进度；逃跑或异常结算不计入。
- 正常结算达标后立即发放该任务的赛季积分，并由后端返回下一轮快照。
- 完成第 3 轮后：`candidates=[]`、无 `acceptedTask`、`needsSelection=false`。

英雄专属任务要求玩家实际使用指定英雄。召唤物、受控单位和额外获得的技能效果按游戏端所有权链归属玩家，避免额外技能导致漏记。

## 4. 刷新规则

刷新只允许在当前轮尚未接取时使用：

- 每天 `1` 次免费刷新；
- 会员可再使用会员积分付费刷新，全天最多 `5` 次；
- 免费次数、付费已用次数和付费剩余次数按整个挑战日累计，不随轮次重置；
- 每次刷新重新生成当前轮三个候选，星级仍各自独立随机；
- 客户端显示快照中的实际下一次费用和剩余次数，不在本地推算扣费。

刷新消耗会员积分；个人、共同和连续完成奖励均发放赛季积分。

## 5. 共同任务

- 全服当天共享一个共同目标，玩家无需报名，只要正常参与并产生正贡献即可进入奖励范围。
- 共同任务按日结算，奖励在次日自动发放并进入奖励记录。
- 共同任务只有贡献档位，个人任务没有档位。
- 默认档位为：贡献前 `10%` 奖励 100，中间 `30%` 奖励 90，其余有正贡献玩家奖励 80；实际值以后端冻结配置为准。
- 共同任务完成与否不影响个人连续完成记录。

## 6. 连续完成

- 当天三轮个人任务全部完成，才算连续完成一天。
- 任意挑战日中断后从第 1 天重新开始。
- 达到最高里程碑后发放对应赛季积分，并从第 1 天开始下一轮循环。
- 连续奖励里程碑及积分由后端配置，客户端展示快照中的当前天数、下一里程碑和奖励。

## 7. 任务池与采集范围

任务池可以大量预设并由后端每日/每轮抽取，包括：击杀 Bot、击杀肉山、伤害、物理/魔法/纯粹伤害、治疗、承伤、助攻、补刀、推塔、眩晕、减速、缠绕、沉默、嘲讽、破坏和负面效果时长，以及对应英雄专属版本。

纯粹伤害和英雄专属控制任务必须以本项目实际加载的英雄技能、override 和 modifier 为依据，不能只参考原版资料。任务文案必须面向玩家，例如“使用冰晶室女对敌方 Bot 造成 300 秒减速”，不得出现“目标秒”等内部字段语言。

## 8. 积分控制

- 低星任务提供较低门槛和较低奖励，高星任务提供更高挑战和小幅更高奖励；奖励增长低于目标增长，避免积分膨胀。
- 三轮基础日收益按默认值范围为 `240`～`360` 赛季积分。
- 共同任务、连续奖励和刷新价格独立配置，正式上线前应按赛季总产出、活跃人数和完成率复核。
