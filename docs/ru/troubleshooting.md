# Решение проблем

## Аддон не запускается или изменения не появляются

Сверьте Node с `.nvmrc`, проверьте установку Dota и Workshop Tools, затем сообщения
`npm install` о пропущенной привязке каталогов. Репозиторий и Dota должны быть на одном разделе.
До переустановки зависимостей проверьте обе ссылки аддона и ошибки сборки; см. [установку](development/setup.md).

Если установке мешает существующий каталог аддона, сохраните изменения перед согласием на замену.
Не удаляйте связанные каталоги `game/` и `content/` как универсальное исправление.
После исправления запустите `npm run start` и убедитесь, что аддон загрузился.

## Ошибки ресурсов частиц

Пример из прежней документации проекта:

```text
Failed loading resource "particles/units/heroes/hero_skywrath_mage/skywrath_mage_mystic_flare_ambient.vpcf_c" (ERROR_BADREQUEST: Code error - bad request)
```

Сначала определите ресурс и его происхождение. Если это локально скомпилированный ресурс аддона,
сохраните копию вне аддона, пересоберите ресурс и перезапустите Dota.
Не удаляйте ресурсы из VPK Valve. Прежний README предлагал удаление, но это не подтверждает причину
и не гарантирует исправление. Проверьте исчезновение ошибки и отображение эффекта.

## Сообщение об ошибке

Укажите шаги воспроизведения, ожидаемый и фактический результат, версию аддона, настройки лобби,
нужные логи VConsole или скриншоты. Уберите ключи и личные данные.
Выбрать подходящий трекер помогут [правила участия](../../.github/CONTRIBUTING.md).
