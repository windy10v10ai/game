# Справочники оригинальной Dota

Для работы с KV способностей и предметов, переводами и ИИ может потребоваться снимок
в `docs/reference/<version>/`. Каталог необязателен, исключён из Git и не входит в клон репозитория.

В [Source 2 Viewer](https://valveresourceformat.github.io/) откройте
`dota 2 beta/game/dota/pak01_dir.vpk`. Извлеките `scripts/npc/` и файлы
`abilities_english.txt`, `abilities_schinese.txt` в каталог версии.

Файлы NPC должны находиться непосредственно в `docs/reference/<version>/`, без дополнительного
вложения `scripts/npc/`. Проверьте наличие файлов локализации и каталога `heroes/`.
Название версии должно соответствовать извлечённым данным игры. Это справочники, а не исходники аддона.
