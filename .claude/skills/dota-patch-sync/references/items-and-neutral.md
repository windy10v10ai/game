# 物品、中立物品与中立生物

按 `SKILL.md` 的分块展开。物品改动的具体改法在 `update-items-override`，这里写范围、批次与本图特有的决定点。样例是 7.42：主 issue `windy10v10ai/game#2782`，紧急修复 #2783，中立 #2784，基础物品覆盖复核 #2785。

## 物品

### 范围

一件原版物品的改动会波及三处（原版覆盖、克隆上位物品、依赖它的配方），`update-items-override` 的每批流程逐处过完。此外还有：

- **商店页签**：`game/scripts/shops.txt`。新版新增的商店装备，不写 KV 不会自动在售，要决定放进哪个页签。恢复的下架物品要补回页签
- **电脑出装池**：`src/vscripts/ai/build-item/bot-build-config.ts`。新装备要加进出装池，电脑才会买，加不加由维护者定
- **抽奖物品池**：`src/vscripts/modules/lottery/item/lottery-items.ts`，按价格档放新装备，档位判断见 `adjust-lottery-tier`
- **升级版装备**：本图自制或克隆的上位物品，核对合成总价是否保持不变，每个配方按「材料新价加新配方费等于原总价」逐条验算

### 决定点（交给维护者）

- 官方移除的物品是恢复还是下架
- 官方新装备是否替换本图原有的自制装备（7.42 例：官方新增锻星炉，本图的星落按维护者手动调整为锻星炉）
- 官方新装备是否上架、放哪个页签、电脑是否购买
- 恢复的物品如果官方的神器卷轴等配方已删，改为自包含配方

### 批次

1. 基础装备覆盖：删与新原版相同的键，子块写法迁移（官方会把单值改成 `{ value, ... }` 子块，覆盖要同步迁移，否则会把官方子键整块盖掉），注释基数同步
2. 上位合成与配方费联动，克隆物品逐件对照新版参考（见 `SKILL.md`「克隆技能与物品」）
3. 恢复与新增
4. 实机检查

## 中立物品

不是每版都改。先读新版 `neutral_items.txt` 的结构与名单，格式变了先在 Dota Tools 实机确认还能用（见 `impact-triage.md`），再改。

- 等级与时间表由本图定，官方等级数或名单变了，先给维护者看官方前后对比与本图方案，再改
- KV 与 `src/vscripts/ai/item/neutral-item.ts`（`GetDefaultConfig`、电脑延后分钟数组）及单测必须同步
- 物品改名时，掉落表、中立 override、电脑中立配置、单测一起改
- 附魔数值跟官方档位，保留本图增强水平，由维护者确认

## 中立生物

- 野怪赏金与经验的覆盖在 `npc_units_neutral.txt`，行尾注释写原版值，改了新版数值要同步注释
- 新野怪按所在档位（小、中、大、远古）对齐营地总量倍率，倍率写在文件头。旧覆盖值低于新原版时补到原版之上
- 营地的增删与刷新位置由地形文件决定，更新地形文件时自动变化，不在这里处理
- 验收用 `npm run dota:check` 的对应检查项，营地是否刷出按本局随机营地池，没刷出的单位直接按名字生成核对
