# bot 插眼

假眼 = 侦查守卫（`item_ward_observer`，配置里 `OBSERVER_*`），真眼 = 岗哨守卫（`item_ward_sentry`，`SENTRY_*`）。

## 结构

| 文件 | 内容 |
|---|---|
| `ward-position-config.ts` | 眼位数据与可调参数。天辉、夜魇各一份，点位按「区域」组织，运行时 `getWardZones` 才转成 `Vector` |
| `ward-decision.ts` | 不查引擎的判定：区域是否空闲、进攻眼位是否启用、路过取点、绕路取点、反隐触发、谁来买眼 |
| `ward-placement.ts` | 采集引擎数据并施法：路过插眼 `Run`，被隐身敌人打到时的真眼 `OnDamaged` |
| `ward-supply.ts` | 团队补眼：假眼全队上限 4，真眼全队上限 3、每人最多 1 个，都给玩家留 2 个库存。持有数阵亡电脑身上的也算。一个电脑只带一种眼：身上有另一种眼的不当买家（两种眼会并成一格组合守卫，脚本施放插出的只会是假眼，反隐插不出真眼）。组合守卫整件按假眼算，其中的真眼不计入真眼持有数，也不会被反隐查找用到。买家只挑活着、确认是电脑、有格子且离空区域不远的人 |
| `../hero/roadside.ts` | 顺路办事里的「带假眼去最近的空区域插眼」 |

## 决定

- **点位按阵营分开**：电脑只用本方那份。每方 24 到 25 个假眼区域，既有己方野区与高地外的防守点，也有河道、敌方野区入口、肉山坑旁的点
- **点位要在相对高位**：不放高台下面、斜坡、坡脚，边缘点往内移，不放己方基地内与己方防御塔附近
- **进攻眼位分两类**：a 类在敌塔攻击距离之外，随时可插。b 类在某座敌方高地塔射程内，数据里带 `requiresDeadTower`（塔单位名里的片段，如 `badguys_tower3_mid`），那座塔被摧毁后才启用。判定是 `ward-decision.ts` 的 `isZoneEnabled`，`WardPlacement.ZonesOf` 用 `CachedTowers()` 的存活塔过滤区域，路过、绕路、补眼三处共用
- **区域里 2 到 3 个备选点**：电脑要在这个区域插眼时随机取一个，落点再在 50 范围内抖动，所以每局眼位不同。区域内任一备选点附近（`sameWardRadius` 900）已有己方假眼，整个区域就不再插。同一区域的备选点最远约 1070，查附近己方眼的半径按「候选距离 + 区域最大跨度 + 去重半径」算（`wardQueryRadius`）。不同区域的点位要隔开 950（去重半径加落点偏移），否则先插下的会占掉邻区，只有成对的进攻眼位（同一片的 a 类与 b 类）例外，先插下的占掉另一个，例外名单写在 `ward-decision.test.ts` 的 `PAIRED_ZONES`
- **同一片区域一次只发一条命令**：路过插眼和绕路插眼共用 `WardPlacement.Claim`，记下命令的落点，60 秒内当作已有眼参与区域去重（`ClaimedSpots` 并进己方眼列表），所以与它相距 900 内的相邻区域也不会再派人。眼是否真正落地另看区域里有没有己方眼。同一个电脑绕路途中不再发路过插眼
- **备用栏的眼也能买能用**：主物品栏满的电脑也买，插眼前把眼换进主物品栏末位，用完后物品整理把被挤开的物品挪回。只靠主物品栏有空位买眼时，后期几乎所有电脑都满格，补不上
- **不再有脚下随机插眼**：眼只插在预设点位。身上带假眼的电脑，在顺路办事的空闲时机，去 1500 范围内最近的空区域插眼，同一区域同一时间只派一个电脑，失败后 60 秒内不再试
- **反隐**：电脑被处于隐身状态的敌方英雄打到，身上有真眼、900 内没有己方真眼，就在脚下插一个，每个电脑 30 秒最多一次。受伤事件走 `ModifierEventHub.RegisterDamageByVictim`，在 `BotBaseAIModifier` 里登记。靠攻击瞬间 `IsInvisible()` 判断，影刃这类出手就现身的隐身不会触发，月刃、永久隐身类会触发
- **真眼预设点位很少**：每方只有肉山坑口与河道神符点 4 个，其余靠反隐触发

## 眼位怎么选的

先对全图每隔 350 取点，在每个点放一个能被树林和地形挡住的视野源，数 1600 半径内 200 间隔采样点的可见比例，再按距离规则筛：离己方基地不小于 2500，离己方防御塔不小于 2100，不在肉山坑禁眼圈内。普通假眼另要离敌方防御塔不小于 1200、离敌方基地不小于 3000。进攻眼位 a、b 类不受这两条限制：a 类只要在敌塔攻击距离之外，b 类本来就在敌方高地塔射程内。所有点位都用真实施法逐个插过。改眼位后要重做这几步，不要手改坐标。
