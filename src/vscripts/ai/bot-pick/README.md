# 电脑选英雄

选英雄阶段结束后按队伍空位补电脑，按定位标签平衡每队阵容。玩家自己选英雄的逻辑在 `modules/hero/hero-pick.ts`。

## 决定

- **按定位标签限制同队人数，不固定阵容**：标签分控制、辅助、肉盾、输出，每队每类设上限，凑不满上限时挑超得最少的。没选固定位置（如每类各 2 个），因为一个英雄常有多个定位，硬卡会经常选不出人。
- **控制超上限的代价最高**：玩家反馈集中在电脑控制过多，其他定位只做软平衡。
- **单人对局控制上限比多人更紧**：单人时玩家独自面对整队电脑，多人时队友能分担。
- **标签按英雄本身定位定，结算数据只用来补漏**：电脑的打法会让数据偏离定位（如电脑辅助很少治疗）。每个英雄最多两个标签，标多了上限会频繁被迫超出。
- **玩家选的英雄计入本队标签**。
- **开发模式不做平衡**：按名单顺序取，性能测试靠它固定出场英雄。
