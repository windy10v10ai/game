# Planning

- Plans describe goals, decisions with reasons, data flow including readers/writers/fields/layers, changed files one line each, and verification; omit signatures, code blocks, and parameter lists.
- Local design drafts go in `docs/superpowers/specs/<YYYY-MM-DD>-<topic>-<purpose>.md`; use `design` for proposals and the implementation scope for records. Do not commit `docs/superpowers/` or recreate `docs/design/`.
