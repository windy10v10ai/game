# Dota references

- For vanilla ability lookup, use supplied system names directly; otherwise resolve Chinese names through `abilities_schinese.txt` and `DOTA_Tooltip_ability_<system-name>`, or hero IDs through `heroes/` and `heroes/npc_dota_hero_<hero>.txt`. Use the latest `docs/reference/` version, including letter suffixes, and consult Chinese/English official descriptions. Ask when candidates are ambiguous.
